# 🛍️ LINE Confection • Boutique Client (React)

Application client officielle avec le design complet (Drops, Stories, Rayons, Coups de cœur, WhatsApp Checkout, Cash on delivery).

## 🚀 Lancement Local
- **Option 1** : Double-cliquez sur `run_local.bat`
- **Option 2** : Tapez dans ce dossier :
  ```bash
  npm.cmd install
  npm.cmd run dev
  ```
  L'application s'ouvrira sur `http://localhost:3000`.

## 🌐 Déploiement sur Render
1. Créez un **Static Site** sur Render.
2. Build Command : `npm run build`
3. Publish Directory : `dist`
